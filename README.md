<h1 align="center">Anomi</h1>

<p align="center">
  Клиент Discord без браузера: лёгкий, на русском, с переработанным оформлением.<br>
  Форк <a href="https://github.com/yapfast/yapfast">Yapfast</a>.
</p>

Anomi работает как обычная программа, а не как веб-страница в обёртке, чем
является приложение Discord. Yapfast, на котором он построен, в простое
занимает около 30 МБ памяти там, где приложение Discord берёт 720 МБ (замер
оригинала; сам Anomi так не замерялся). Серверы, личные сообщения, ветки,
форумы, друзья, звонки, демонстрация экрана, камера, GIF и стикеры работают
как в Discord.

## Два интерфейса

В этой ветке у Anomi два клиента на одном ядре и одних настройках:

- **`anomi`** — новый интерфейс на [iced](https://iced.rs). В него перенесены
  все экраны; он легче прежнего по памяти и процессору.
- **`yapfast`** — прежний интерфейс на Slint. Он остаётся в ветке, пока новый
  проверяется на настоящем Discord.

Оба читают один `layout.json` и один вход в Discord: между ними можно
переходить, ничего не настраивая заново. Запускать одновременно нельзя —
второй передаст управление первому.

Замеры на одной машине и одних тестовых данных (подробно:
[docs/measurements/README.md](docs/measurements/README.md)):

| | Slint | iced |
| --- | --- | --- |
| Память в простое, личные сообщения | 37,2 МиБ | 30,6 МиБ |
| Память на канале с картинками | 50,9 МиБ | 37,1 МиБ |
| Процессор в звонке, окно впереди | 4,9 % | 3,7 % |
| Процессор при просмотре трансляции | 9,5 % | 6,2 % |
| Шумный сервер, окно за другим окном | 1,07 % | 0,65 % |
| Прокрутка ленты | 18,7 % | 19,5 % |

Память здесь — анонимная память процесса, как её считает документ с
замерами; процессор — доля одного ядра.

## Что есть в Anomi сверх Yapfast

- **Русский язык.** Весь интерфейс переведён и по умолчанию русский.
  Английский включается в «Настройки → Внешний вид».
- **Плавный интерфейс.** Окна, меню и подсказки открываются с анимацией, а не
  рывком. Анимации отключаются настройкой «Воспроизводить GIF, эмодзи и
  стикеры → Никогда».
- **Новое оформление.** Заново сделаны панель звонка, редактор профиля,
  настройки и диалоги.
- **Темы.** Добавлены две тёмные: Midnight (почти чёрная) и Black (чисто
  чёрная, для OLED). В остальных десяти исправлены цвета, из-за которых поля,
  ползунки и переключатели сливались с фоном.
- **Превью трансляций.** На плитке участника видно, что он показывает, ещё до
  того, как вы начали смотреть.
- **Не мешает играм.** Когда окно не на переднем плане, свёрнуто или в трее,
  Anomi ничего не перерисовывает: в новом интерфейсе поток окна в это время
  не просыпается вовсе, даже в звонке с открытой трансляцией.
- **Push-to-talk и клавиши звонка** работают, когда окно позади игры или в
  трее.
- **Звонок не рвётся при переносе.** Если админ перетащил вас в другой
  голосовой канал, разговор продолжается.
- **Проверка микрофона.** В настройках голоса можно послушать себя так, как
  вас слышат в звонке.
- **Трансляция настраивается на лету.** Во время демонстрации экрана в новом
  интерфейсе меняются разрешение, частота кадров и качество кодирования, а
  также звук, не останавливая эфир.
- **Видео с телефона.** Ролики в HEVC, которые снимает iPhone, проигрываются,
  а повёрнутые показываются правильной стороной.
- **Ctrl+F** открывает поиск по переписке.
- **Свои шрифты.** Интерфейс можно рисовать своими файлами шрифта:
  «Настройки → Внешний вид → Шрифт».
- **Темы файлами.** Свою тему можно сохранить в файл и загрузить из файла.
- **Чёткие эмодзи.** Стандартные эмодзи в тексте больше не зубчатые.
- **Пустой звонок завершается сам.** Если в звонке в личных сообщениях вы
  остались одни, Anomi выйдет из него через выбранное время.

Часть этого взята из запросов на слияние, которые в оригинале ещё не приняты,
и доработана. Чьи они: [CREDITS.md](CREDITS.md).

Если у вас уже стоит Yapfast, Anomi подхватит его настройки и вход в Discord:
заново входить не нужно.

## Сборка и запуск на Linux

Готовых сборок для скачивания пока нет: Anomi собирается из исходников.

### С Nix

Проект собирается в закреплённом окружении [Nix](https://nixos.org), которое
приносит нужные Rust, Clang и библиотеки. Из папки проекта:

```sh
# Посмотреть интерфейс без аккаунта
nix develop path:./nix --command cargo run --locked -- --preview

# Запустить по-настоящему
nix develop path:./nix --command cargo run --locked --release
```

### Без Nix

Нужны [rustup](https://rustup.rs), который сам поставит Rust 1.97.1 из
`rust-toolchain.toml`, и пакеты из `makedepends` в
[packaging/arch/PKGBUILD](packaging/arch/PKGBUILD). На Arch это:

```sh
sudo pacman -S --needed rustup clang cmake curl git llvm nasm pkgconf protobuf python
```

Без `nasm` сборка не пройдёт. Дальше обычный cargo; C и C++ собирает
clang, как в PKGBUILD:

```sh
export CC=clang CXX=clang++

# Быстрая сборка для работы над кодом: интерфейс в ней не оптимизирован
cargo build --locked --profile fast
target/fast/yapfast --preview

# Сборка на каждый день
cargo build --locked --release
target/release/yapfast

# Новый интерфейс на iced
cargo build --locked --release -p anomi-app --bin anomi
target/release/anomi            # --preview покажет его без аккаунта

# Ярлык в меню приложений и значок для этого пользователя
scripts/install-desktop-entry
```

Cargo сам скачает те же архивы libwebrtc и Skia, что закрепляет окружение
Nix. Первая сборка идёт несколько минут.

Discord привязывается по QR-коду: в приложении Discord на телефоне откройте
«Настройки → Сканировать QR-код» и наведите камеру на код в окне.

## Что нужно знать заранее

- **Риск для аккаунта.** Anomi входит в Discord как обычный пользователь, а
  правила Discord сторонние клиенты запрещают. Блокируют за это редко, но
  гарантий нет. Если аккаунт терять нельзя, не пользуйтесь сторонними
  клиентами.
- **Обновлений нет.** Anomi сам не обновляется: чтобы получить новое, его
  пересобирают из исходников.
- **Проверено только на Linux.** Сборки для Windows и сборки с Matrix у форка
  никто не запускал.
- **Новый интерфейс проверялся в основном на тестовом сервере Discord.**
  Каждый экран сверен с прежним интерфейсом на одних и тех же данных, но на
  настоящем Discord и настоящем рабочем столе (буфер обмена, перетаскивание
  файлов, уведомления, камера, показ экрана) он обкатан меньше прежнего.
