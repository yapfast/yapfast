<h1 align="center">Anomi</h1>

<p align="center">
  Форк <a href="https://github.com/yapfast/yapfast">Yapfast</a>: нативный клиент Discord без браузера, с русским интерфейсом и переработанным оформлением.
</p>

Anomi, как и Yapfast, сам говорит с API Discord и рисует своё окно на
[Slint](https://slint.dev) и Skia, без Chromium и веб-страниц. Всё, что умеет
оригинал, на месте: серверы, ЛС, ветки, форумы, друзья, звонки, демонстрация
экрана, камеры, GIF. Подробно о возможностях оригинала рассказывает его
README, сохранённый в [docs/README.upstream.md](docs/README.upstream.md).

## Чем отличается от Yapfast

- **Русский интерфейс.** Слой переводов: тексты интерфейса берутся из
  gettext-файлов в `lang/` через крейт `crates/yapfast-lang`, а язык
  выбирается в настройках, в разделе «Внешний вид». Пока язык не выбран,
  интерфейс на русском, какой бы ни была система; английский остаётся в
  списке. Как это устроено: [docs/translations.md](docs/translations.md).
- **Анимации интерфейса.** Меню, всплывающие окна и диалоги появляются и
  закрываются плавно, наведение и выбор меняются мягко. Если в настройке
  «Воспроизводить GIF, эмодзи и стикеры» выбрано «Никогда», интерфейс не
  двигается.
- **Переделанное оформление.** Док звонка, редактор профиля, настройки и
  диалоги перерисованы заново.
- **Темы.** Цвета выправлены во всех двенадцати темах, добавлены тёмные
  Midnight и Black (на чистом чёрном, для OLED). Список тем:
  [docs/themes.md](docs/themes.md).
- **Превью чужих трансляций.** В доке звонка видно, что показывает
  трансляция, ещё до того, как начать её смотреть.
- **Меньше нагрузки в фоне.** В окне не в фокусе анимированные эмодзи и
  полосы загрузки замирают, а их таймеры останавливаются, так что окно не
  перерисовывается впустую, пока вы, например, играете. Эмодзи вне экрана
  таймер не будят.
- **Запросы на слияние из оригинала**, которые там ещё не приняты: видео в
  HEVC и повёрнутые видео, Ctrl+F для поиска, меньше перерисовок, проверка
  микрофона, выбор звука трансляции. Авторы и что доделано в форке:
  [CREDITS.md](CREDITS.md).
- **Своё имя и значок.** Если у вас уже стоит Yapfast, настройки и вход в
  Discord подхватятся сами: заново входить не нужно.

## Сборка и запуск на Linux

Сборок для скачивания у форка нет, только сборка из исходников.

### С Nix

Проект собирается в закреплённом окружении [Nix](https://nixos.org), которое
приносит нужные Rust, Clang и библиотеки. Из папки проекта:

```sh
# Посмотреть интерфейс без аккаунта
nix develop path:./nix --command cargo run --locked -- --preview

# Запустить по-настоящему
nix develop path:./nix --command cargo run --locked --release
```

### Без Nix

Нужны [rustup](https://rustup.rs), который сам поставит Rust 1.97.1 из
`rust-toolchain.toml`, и пакеты из `makedepends` в
[packaging/arch/PKGBUILD](packaging/arch/PKGBUILD). На Arch это:

```sh
sudo pacman -S --needed rustup clang cmake curl git llvm nasm pkgconf protobuf python
```

Без `nasm` сборка не пройдёт. Дальше обычный cargo; C и C++ собирает
clang, как в PKGBUILD:

```sh
export CC=clang CXX=clang++

# Быстрая сборка для работы над кодом: интерфейс в ней не оптимизирован
cargo build --locked --profile fast
target/fast/yapfast --preview

# Сборка на каждый день
cargo build --locked --release
target/release/yapfast

# Ярлык в меню приложений и значок для этого пользователя
scripts/install-desktop-entry
```

Cargo сам скачает те же архивы libwebrtc и Skia, что закрепляет окружение
Nix. Первая сборка идёт несколько минут.

Discord привязывается по QR-коду: в приложении Discord на телефоне откройте
«Настройки → Сканировать QR-код» и наведите камеру на код в окне.

## Оговорки

- Anomi входит в Discord как обычный пользователь. Сторонние клиенты
  нарушают условия использования Discord, и аккаунт может быть заблокирован.
  На практике за клиент блокируют редко, но гарантии нет. Если потерять
  аккаунт нельзя, не пользуйтесь сторонними клиентами.
- Выпусков нет, автообновления нет. Проверка обновлений в «Настройки → О
  приложении» выключена: она смотрела бы выпуски оригинала, а они встали бы
  поверх форка. Обновляется Anomi пересборкой из исходников.
- Сборки для Windows и сборки с Matrix у форка не проверялись.
