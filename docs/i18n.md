# Languages

Yapfast reads in English, German and French, and the settings page can offer
any of the 32 languages Discord has once someone writes its translations.

## How a text is translated

Every text is its English wording; the wording is also its key. There is no
message id to invent and no English file to keep in step.

- In Slint, a text is `@tr("Mute server")`. A text with a value is
  `@tr("Slowmode: {}", seconds)` (`{0}`, `{1}` when a language needs another
  order).
- In Rust, `yapfast_core::i18n::tr("Mute server")` answers with the text in
  the chosen language. A text with values is
  `fill(tr("Kick {}"), &[&name])`; `fill` puts the values in for `{}` in order
  and for `{0}`, `{1}` by place. A count that changes its word is
  `trn("{n} friend", "{n} friends", count)`.
- A text with no translation reads in English, so a missing string is never
  blank.
- A word that means two things in English takes a context, for example the
  months and weekdays of the clock (`tr_ctx("month", "May")`).
- Dates and times come from `clock.rs`, which asks the catalog for the weekday,
  month, period (AM/PM) and date patterns, so a language rewrites all of them
  in its `.po` file.

Both sides read the same files, `translations/<code>/LC_MESSAGES/yapfast-ui.po`,
where `<code>` is Discord's code for the language (`de`, `fr`, `pt-BR`).
`crates/yapfast-ui/build.rs` hands them to Slint, which carries them in the
program and switches with `slint::select_bundled_translation`. Rust reads the
same files with its own small parser in `crates/yapfast-core/src/i18n.rs`.

Slint also compares texts, for instance a person's status against
`@tr("Muted")`. The Rust side must therefore produce its status with
`tr("Muted")`, never a bare literal, or the comparison fails in every language
but English.

## Which language shows

The layout saves `interface_language`, Discord's code for the choice. Unset, it
follows the system language (`Language::system`), and English when Yapfast has
no translation for that. The settings page lists English (US and UK) and every
language that has translations (`Language::offered`).

## Keeping the files in step

`scripts/i18n` needs only Python 3.

    scripts/i18n extract     write translations/yapfast-ui.pot from the code
    scripts/i18n update [L]  merge the texts into each language's .po file
    scripts/i18n check       placeholders, plural forms, coverage, style
    scripts/i18n todo L      list the texts L has not translated

`update` finds the texts by reading the Slint and Rust sources (`@tr(`, `tr(`,
`tr_in(`, `trn(`, `tr_ctx(` and the clock's phrases). It adds new texts empty,
keeps the translated ones and says which texts the code no longer has. `check`
fails when a translation changes the placeholders of its text, has the wrong
number of plural forms, contains an em dash, or does not keep the text's
leading and trailing spaces.

Translate with the product's wording in mind: Discord's own terms for Discord
features, and the sentence in the register the language uses for a program
(German "du", French "vous").

## Adding a language

1. Add the language to `LANGUAGES` in `scripts/i18n` with its plural rule
   (`one-other` for German or English, `zero-one-other` for French; add a key
   to `PLURALS` for another rule).
2. `scripts/i18n update CODE` writes `translations/CODE/LC_MESSAGES/yapfast-ui.po`
   with every text empty.
3. Translate the texts. `scripts/i18n todo CODE` lists what is left.
4. In `crates/yapfast-core/src/i18n.rs`, add `translated` to the language's
   `locale!` line. That embeds its file and makes the settings page offer it.
5. `scripts/i18n check` must pass.
6. Look at the screens: German and French run 20 to 40 percent longer than
   English, and a label that fits in English can overflow. The languages that
   need more than a plain Latin font (Chinese, Japanese, Korean, Thai) also
   need their glyphs; check the bundled fonts first.

## What stays English

Names (Yapfast, Discord, Matrix, Nitro, Klipy), key names, protocol and
file-name literals, log and crash messages, the emoji names Discord sends, and
the few Windows tray entries built with the `w!` macro at compile time.

Some texts are not yet translated because they are not produced by this
interface layer:

- Discord's `<t:...>` timestamps in messages, which `yapfast-discord` formats
  with English patterns.
- Texts the core builds before the UI sees them, such as the audit log entries
  and some notices.
- The names of Discord's own things that Discord sends already localized or in
  English (emoji names, sticker packs, activity names).
- Command-line help and `--version` output.
